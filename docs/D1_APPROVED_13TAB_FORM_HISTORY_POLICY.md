# 確定仕様：現行13シートのフォーム回答履歴は将来D1の参照専用領域に分離保存（ユーザー承認A）

承認日：2026/11/21。基準：[第25工程READ ONLY調査](D1_PHASE25_FORM_ANSWER_HISTORY_CONFLICT_AUDIT.md)、[13シートの正本候補指定と旧3シートのサンプル除外](D1_PHASE24_EXCLUDE_LEGACY_SAMPLE_3TAB.md)、[仕様優先順位](SPEC_PRIORITY_POLICY.md)。

## ユーザーの明示承認内容（判断A）

> 現行13シート版のフォーム回答履歴を、将来のD1で現役業務データから分離した参照専用履歴として保存する設計を進める。実データの移送・本番反映は承認しない。

1. 将来の保存対象は現行13シート「全力☆スマッシュ 運用管理ツール」の**「フォームの回答」**（現在の観測値は**115行、A:Gの7項目**）。移行直前の原子性・原本バックアップ・件数再調査が必要。**115行を永続的に固定件数として移行検収してはならない**。
2. その**全行を独立した参照専用履歴**で扱い、過去日程73行、メール＋開催日の反復11追加行、同一人名で反対の出欠を持つ回答を勝手に省略・最新行選択・上書き・自動名寄せしない。記録の順序・元7項目・元の出典と取得時点を追跡できる設計にする。
3. **独立領域は現役の練習日程、参加者、集金、収支、会員、LINE ID、試合に副作用を持たせない。** 過去の日程を自動作成・受付有効化しない。元回答のメール・名前から参加者IDを推定せず、現役の出欠・集金・残高を再計算しない。
4. 旧3シートのテスト用電子会計帳簿および21シートの架空検証データは**業務移行元から除外**。旧Google原本/bkは変更しない。
5. **この承認は設計のみ**。Google実データのコピー/エクスポート/移送、Cloudflare D1実書込やmigration apply、GAS/Worker/LINE/LIFF/API更新、本番反映、同意/保存期間/閲覧権限の最終確定は**含まない**。

## 設計上の必須制約

- **元行は不変**。取得単位の識別子（snapshot_id）とその取得時点での元行番号を組合せる。行番号をGoogleシート内の永続IDと誤認しない。複数スナップショットは上書きせず保全し、版間差分を明示レビューする。
- 対象列はタイムスタンプ、メールアドレス、開催日、お名前、出欠、区分、備考。日付/名前/メールが一致することだけでは同一人物・同一回答と確定しない。過去に削除/修正された履歴は今回の115行から復元不能。
- 表示値の7セル配列のみでは、ネイティブDate値・タイムゾーン・書式・数式を**厳密に復元できない**。実移行の前に元Googleネイティブバックアップ、セル型/式/表示値、安定した取得時点の整合性・行数・SHA/リードバック、二重送信時の整合・復旧を別途確認。
- メール・氏名・備考・日時は個人情報を含み得るため**公開GitHub、Actionsログ、公開ブラウザの静的ページ、匿名アクセスに転載しない**。参照APIも現時点では**未実装・公開禁止**。最終閲覧対象（暫定：管理者のみ）、操作監査、本人確認、保存期間、同意、退会時の取り扱いはユーザー判断とプライバシーの検証が必要。
- D1第16/17/20工程承認済みの操作IDの対象不一致拒否、試合監査原子的更新、試合削除アーカイブの確定仕様と衝突させない。現行の収支確定順・確定済み残高保護と料金・ロック・退会/再入会の仕様は不変更。

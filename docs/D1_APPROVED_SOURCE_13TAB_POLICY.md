# D1正本候補の確定選択：13シート版と旧3シート参照専用

2026/11/21　第21工程後のユーザー明示承認A。

**正本候補（D1への将来の移行元）：**「全力☆スマッシュ 運用管理ツール」13シート版。

**READ ONLYの参照元：**旧形式「運用_全力スマッシュ出欠集金管理表」3シート版。両者を自動統合しない。差分と旧台帳固有履歴がある場合は、追加ユーザー判断までD1へ取り込まない。

本承認は「実データ移行・コピー・Cloudflare D1への保存」を許可するものではない。既存GAS/Google Sheetsが当面の業務正本。会員/権限、全体収支確定順・残高/繰越、既存参加者/旧履歴、試合SHA不一致46版、47 GAS_ONLY API、LINE/LIFF、本番の安全ゲートを維持する。

2026/11/21の読み取り専用差分で、旧参照台帳には現行候補の日付範囲より古い**日付入り収支行6行（ユニーク日付5）**があり、現在の13シート候補の日付5種との**日付共通0**を確認。ただし旧収支が現行opening残高に繰り越されているか、実取引であるか、確定済みかは未確認。このため旧会計の直接取込/再合算は**禁止**。旧履歴のD1参照専用アーカイブ化の要否は次の別承認。

# 全力☆スマッシュ 権限・LINEメニュー仕様（v0.16.1方針）

## 合意した3権限
- 管理者 (`admin`)
- 当番担当 (`duty`)
- 一般メンバー (`member`)

ビジターは未登録者であり第4のアプリ権限ではない。QR閲覧専用APIだけを利用する。
開催日ごとの試合担当・集金担当の割当は行わない。登録済み当番担当は、全開催日で必要な運営業務を共同実施できる。

## リッチメニュー（将来実装）
| 状態 | 表示メニュー |
|---|---|
| 公式LINE友だち追加前のビジター | リッチメニューなし。QRでブラウザ閲覧 |
| 友だち追加済み・承認前 | 新規登録（必要なら説明・承認待ち確認） |
| 一般メンバー | 参加連絡・予定修正／日程確認／参加者一覧（閲覧）／対戦表 |
| 当番担当 | 一般メンバー4件＋運用管理ツール |
| 管理者 | 当番担当と同じ5件（運用管理ツール内で権限に応じて機能を表示） |

リッチメニューはLINE Messaging APIの**ユーザー単位のリッチメニュー**で表示し、友だち追加・承認・権限変更・無効化の各イベントで自動更新する。現在LINE Official Account Managerで作成済みのデフォルトメニューだけではユーザー別の出し分けができない。

| 対戦表閲覧 | ○ | ○ | ○ | QR限定 |
| 対戦表閲覧QR発行 | ○ | ○ | ○ | × |
| 試合生成・進行操作・再生成 | × | ○ | ○ | × |

| 収支表の閲覧・編集・確定 | × | ○ | ○ | × |
| 確定済み集金・収支の確定解除 | × | × | ○ | × |

「参加者一覧（閲覧）」と「参加者管理（編集）」は別機能。参加区分（ビジター、学生等）は課金・参加区分であり、アプリの操作権限（管理者、当番担当、一般メンバー）とは独立させる。

## 登録フロー
1. 未登録者は公式LINEを友だち追加し「新規登録」からLINE認証して申請。
2. 管理者が運用管理ツールの「メンバー・権限管理」で承認・却下。
3. 承認時は一般メンバーとして登録。ユーザー単位リッチメニューを割り当てる。
4. 管理者が権限を変更するとリッチメニューを再割当。サーバーは毎回最新権限を検証する。
5. 最後の管理者を削除・降格できない仕組み、監査ログを維持。

## 画面分担
- **対戦表アプリ `match.html`**：閲覧・当番/管理者の試合進行操作・ログイン済み3権限の「閲覧QR」（タイトル右端）。
- **ゲスト閲覧 `guest.html`**：LINE不要、上部更新、QRの開催日限定トークン、有効期限付き、表示名・試合だけ。
- **運用管理ツール `live.html`**：当番担当の集金・現金確認・参加者管理・収支表。管理者だけ「練習日程」「メンバー・権限管理」と「確定解除」。
- 既存v0.16の「メンバー・権限管理」は暫定的に`match.html`にある。運用管理ツールに移し、対戦表側から外すのは**未実装**。

- LINE Messaging APIのユーザー単位リッチメニュー作成、Webhook連携、自動切替は**未実装**。現行A/B/Cメニューの変更・本番反映は行っていない。

- 参加者メンテナンス時は出欠回答・集金と試合生成済みデータの整合性を検証する。

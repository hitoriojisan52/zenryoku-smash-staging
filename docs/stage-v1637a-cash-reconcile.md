# v0.16.37a 現金確認（検証UIのみ・帳簿非変更）

2026-11-18。対象：接続ステージングの運用管理LIFF。**本番・本番スプレッドシートには適用しない**。

## 過去の合意を踏襲
- 「現金確認」は現金の枚数集計を助ける**任意**の補助機能。
- 帳簿残金は「共有財布の前回繰越＋収入−支出」の理論値。金種枚数を入力してもその残金を修正しない。
- 現金確認により集金記録・全体収支管理表に収入/支出/調整を自動記録しない。
- 現金確認の履歴は将来必要なら別シートに保存する案を再検討するが、**この版では保存しない**。
- 当番/管理者の既存LIFF認証・権限を利用する。管理画面の未完成メニュー（練習日程/参加者管理）は引き続き無効。

## 実装
- 運用管理 → 現金確認を有効化し、選択中の開催日を初期値として現金確認ダイアログを開く。確認対象日は当日以前に限定。
- 日本円の10種（金額：10000,5000,2000,1000,500,100,50,10,5,1円）を入力。枚数は0〜9999の整数のみ。未入力は0枚、入力が一度もない間は差額を「—」で表示。
- 日付の年月を使って**既存の** `/api/ledger` （GAS `ledger.list`）を呼び出し、該当日の最後の記帳行の「残金」を表示。
- 指定日に記帳行が無い場合、前日の残金や月繰越をその日の帳簿残金として扱わず、「指定日の収支行がありません」と警告して**差額を出さない**。
- 指定した月の対象日までに未確定行があれば「暫定値」を案内する。既存APIの月外の未確定履歴までは判断しない。
- 実査合計−帳簿残金を差額として表示。一致/プラス/マイナスの判定を示す。枚数リセット/帳簿の再読込/閉じるを用意。
- 新たなGAS/Workerエンドポイント、スプレッドシートの列、金銭操作、操作履歴追加は**一切不要**。日時・金額はIDトークンで認証された当番・管理者に既存APIが返す。

## UI・安全
- UI読み込み・手動再読込中は既存`SMStageUX.run`の全画面ロックを利用する。8秒ごとのホーム自動更新とは独立。
- 金額はテキスト挿入（`textContent`）で表示し、ユーザー入力のHTMLを解釈しない。
- 日付変更時には前回帳簿結果を消してから読み直す。読込失敗時に旧残高で差額を出さない。
- 退会検証画面・本番環境を変更せず、既存の集金同時処理/冪等性/確定済み行制御に触れない。

実機確認手順：
1. 運用管理 → 現金確認。2026/11/16 の帳簿残金が0円と表示されること。
2. `1,000円×1枚` と入力し、実査合計1,000円・差額 +1,000円と表示されること。
3. 枚数リセット → 実査・差額が「—」に戻ること。
4. 2026/11/17 など帳簿行がない日付を選ぶと、残金は「—」で警告が表示され、差額が出ないこと。
5. 閉じて既存集金画面に戻り、集金額・残金・集金記録が変わっていないこと。

※検証環境の11/16帳簿残金が今後変われば、手順1は当日の実際の帳簿値に読み替える。

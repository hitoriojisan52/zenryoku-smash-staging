# v0.16.41 | 申請日時の日本語表示・ビジター登録画面統合・ボタン共通仕様

対象：**検証環境のみ**。本番・GAS・Worker・Google Sheets のデータ変更なし。

## 対応要件
1. 申請日時が `Wed Nov 18 2026 20:10:47 GMT+0900 (GMT+09:00)` と表示される不具合を修正。
2. 「却下」ボタンは確実に赤色で表示する。色・タップサイズ・ボタンの配置意味を運用管理・対戦表・閲覧画面・ビジター管理・メンバー管理で統一。
3. 独立した「自分の申請」メニュー／ダイアログを廃止。**ビジター登録ダイアログ内の最上部**に「自分の申請」一覧と更新ボタンを置き、**その下**に「＋ 新しいビジターを申請」フォームを置く。

## 日時の正規化
`date-format.js` にある共通JST変換 `SMDate.dateTimeJst(value,weekday=true)` に、`weekday=false` の省略曜日オプションを追加。
- Google SheetsのDate表示 `Wed Nov 18 2026 20:10:47 GMT+0900 (GMT+09:00)` → `2026/11/18 20:10`
- `2026-11-18T11:10:47Z` → `2026/11/18 20:10`
- タイムゾーンの付かない `2026/11/18 20:10:47`／`2026-11-18 20:10:47` は日本時間として解釈。
- 変換できない値は、英語の元文字列を画面へ生表示しない。「日時を確認できません」を表示。
- 他画面の既存フォーマット（曜日付き）はデフォルト維持。

## ビジター登録の画面構成
```text
👤 ビジター登録
├─ 📋 自分の申請　　　　　　　　　　[更新]（青）
│  ├─ 申請カード：日時、氏名、開催日、承認待ち／承認済み／却下済み
│  └─ …（申請がない場合は共通の「案内」メッセージ）
├─ ────────────────────────
└─ ＋ 新しいビジターを申請
   ├─ 参加希望日
   ├─ お名前／氏名カナ／備考
   └─ [キャンセル]（灰） [確認する]（緑）
```
- 登録画面を開く際、開催日と「自分の申請」を並列読込。
- 申請完了後はダイアログを閉じず、入力欄をクリアして**上の申請一覧を再読込**。
- LINEの一般メンバー経由でも、当番／管理者の運用管理メニュー経由でも同じフォームを使う。
- 独立の「📋 自分の申請」メニュー・ダイアログ・重複DOM/JSイベントを削除。
- 一般メンバーは自分が申請したものだけを表示する既存のGAS認可を維持。

## ボタン色・配置の共通規約（全画面）
| 色・役割 | 適用先 |
|---|---|
| 青 `btn-blue` | 表示・画面移動・更新・参照・コピー |
| 緑 `btn-green` | 承認・申請・追加・保存・確定・設定変更を確定する操作 |
| 赤 `btn-danger` | 却下・削除・リセット・取り消し、試合進行終了 |
| 灰 `btn-outline` | 閉じる・キャンセル・戻る・軽微な補助操作 |
| 非活性 | 共通の灰色＋押下不可。権限と実データに合わせて制御 |

共通CSS `stage-ui.css` で背景・文字色を定義（従来は `btn-danger` のCSS定義がなく、却下が赤くならなかった）。すべての操作ボタンは原則44px以上のタップ領域と最低88pxの確認画面ボタン幅。スマートフォンの狭い画面では適度に折り返す。

管理画面のビジター「承認」は緑、「却下」は赤。メンバー登録管理でも同色。却下の確認ボタンも赤。既存の確認ダイアログとエラーダイアログの枠線・タイトル色の**意図的な差**は変更しない。削除・集金・権限・日程・対戦表・収支のAPIロジックも変更しない。

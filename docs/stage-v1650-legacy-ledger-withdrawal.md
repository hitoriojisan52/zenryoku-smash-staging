# v0.16.50 staging: 退会履歴の旧仕様とv15収支表の復元

- 退会履歴：折りたたみ`details`（初期閉）、「退会履歴を見る」、「退会履歴はありません。」、履歴APIが配列を返さない場合は非表示、氏名・状態・退会日時の簡素な行に戻す。退会日時が空なら行を表示しない。状態判定は`completed`対その他の既存判定を維持。
- 収支表：添付の`zenryoku_smash_poc_v15`画面を参照。幅広の表、前月繰越行の淡黄色、操作セル左寄せ、修正・削除・確定の固定スロット。不要な操作は隠さず`disabled`。確定済み行の管理者用確定解除は既存機能を維持。月別表示・残高計算・データ操作権限は変更しない。
- 利用者一覧：通常メンバーに対する退会ボタンを行内に用意。ただし**現時点では非活性**。現在のWorkerとGASは架空テストメンバー1名にしか退会を許可しない。実在メンバーの退会は現行安全ゲートにより拒否されるため、ボタンを有効化して成功を装わない。管理者本人と管理者は対象にしない。
- 本番・Worker設定・退会APIの破壊的な安全ゲートは変更しない。通常メンバー退会の有効化には、対象者の事前確認、既存シートのバックアップ、再入会・LINE ID紐付けと集金履歴の保持確認、Worker/GAS両側の制限付き移行・実機検証が必要。

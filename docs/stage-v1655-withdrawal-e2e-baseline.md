## 3. 必要なLINE実機操作（ChatGPTでは認証代行できない）

1. **管理者のLINE**で[検証用運用管理LIFF](https://liff.line.me/2012602642-XBSkXduO)を開く。
2. **メンバー権限管理 → 利用者一覧**を開く。
3. **架空退会検証1653**のカードがあり、**「退会」ボタンが有効**であることを確認。ここで非活性なら押せない原因を報告し、GAS/Workerのゲートや権限を調査する。設定値を無条件に再入力させない。
4. 「退会」を押し、`【退会確認（1/2）】`、`【退会確認（2/2）】`で**退会する**を押す。
5. 成功後はカードが利用者一覧から消え、折りたたみの「退会履歴を見る」に**架空退会検証1653（退会済み）**が表示されることを確認。
6. 通信エラーや操作結果不明が出たら**再押下しない**。最新一覧を更新し、結果／`processing`を確認する。
7. 画面結果だけをChatGPTに返信する（例：`退会ボタン有効、二段階確認、退会成功、履歴に表示`）。LINE IDトークン・アクセストークン・シークレット等は送らない。

## 4. ユーザー操作後にChatGPTがGoogle Sheetsで行う照合（新チャットでも必須）

| シート | 検証する変更・不変条件 |
| --- | --- |
| `メンバー` | 退会対象の行を削除。管理者の有効行とLINE紐付けは不変 |
| `チーム所属` | 退会対象の所属行を削除。別メンバーの行は不変 |
| `登録申請` | 旧LINE IDの申請行を削除。他人の申請は保持 |
| `閲覧リンク` | 旧メンバーの発行リンクのrevokedAtが埋まる。発行履歴自体は削除しない |
| `退会履歴` | 対象旧IDが1行追加され、state=`completed`・withdrawnAt・operationId記録。**LINE IDは記録しない** |
| `操作履歴` | `member.manage.withdraw`が追加され、過去行は変更なし |
| `出欠回答`・`集金記録` | 対象旧IDの行・値をそのまま維持 |
| `全体収支管理表`・試合関連 | 既存行・金額・確定状態を変更しない |

途中失敗・`processing`時は手動でむやみに再実行・削除せず、復旧方針を既存仕様に照らして判断。

## 5. 再入会の試験制約

- **同じLINEアカウントによる本当の再入会E2E**には、管理者とは別の**実在する検証用LINEアカウント**が必要。今回の架空退会検証1653は擬似LINE IDのため、LINEアプリから本人としてログインできない。
- GASの`member.apply`、`member.manage.decide`、新しいメンバーID発行、過去履歴保持、`processing`中の再申請拒否については`tests/check-stage-withdraw-rejoin-v1653.cjs`で**実GAS関数を使うモックSheets試験済み**。これはLINEログイン実機検証と区別する。
- ユーザーが実在する別LINEアカウントを検証に利用できる場合、登録申請→管理者承認→退会→同じLINE IDで新規申請→承認→**旧IDとは異なる新ID**の試験に進める。アカウントのLINE IDや認証トークンをチャットに貼り付けない。

# v0.16.58 — 全体収支管理表のスマホカード表示と全画面共通ボタン余白

更新日：2026/11/19。直前の管理者LINEでの権限変更→復元、収支確定→確定解除の実機成功を前提に、ユーザーから添付された**既存アプリのスマホ画面**を参考にレイアウトのみ調整する。

## 対象と既存機能の保護

- **スマホ幅（900px以下）**の全体収支管理表：既存の7列テーブルDOM（日時／費目／集金額／支出／残金／確認者／操作）を縦方向の1件1カードに再配置する。横スクロールを使わない。カードは日付・残高、項目、収入・支出、確認者、状態・操作の順。前月繰越は淡黄色で操作なし。
- **広い画面（901px以上）**：従来の7列テーブル、金額列、左側の操作ボタン・確定色等を基本維持。カードへの切替はCSSだけのため、同じデータと同じイベント処理を使う。
- ダイアログ上部は **「全体収支管理表」見出し／「＋追加」／「✕閉じる」** を同じ行にする。既存 `dialog-close.js` の共通ツールバーが元のボタンを移動するため、新しいボタンやクリック処理は増やさない。スマホの極小幅でも再折り返ししないよう収支表に限るスタイルを追加。
- **「権限（デモ）」表示を削除**。実際の `S.actor.role` はLINEトークンとWorker/GASの認証結果から取得し、デモのセレクタでは変更できなかった。UI以外の権限処理を改変しない。
- **管理者の確定済み収支**：「確定解除」一つのみ、緑ボタン。**当番担当の確定済み収支**：非活性「確定済み」一つのみ。**未確定収支**：「修正」「削除（赤）」「確定」3枠（条件を満たさなければ非活性）。未来日・過去月/同日順序・GASサーバー拒否などは元のまま。
- UI共通のボタン縦paddingを **7〜8px中心→5〜6px中心に小幅縮小**。40/44/52pxの既存下限と44px推奨タップ範囲、ボタン色、警告文、グローバルロック、自動更新の非ブロックは変えない。`stage-ui.css?v=1658` を運用管理／対戦表／対戦表閲覧／ゲスト閲覧で共通適用。
- 既存の **収支表データ構造・月切替・前月繰越・確定順序・残高計算・集金・退会・会員/当番権限・GAS/WorkerのAPI/保存処理** は変更なし。

# v0.16.60 — 診断表示の撤去・共通UI圧縮・参加者の登録日/更新日

2026/11/19 ユーザー依頼。既存業務仕様の保護と本番事前承認を維持する。

## 対戦表
- 「検証用：自分のLINEユーザーIDを確認」「起動時間を確認」の2つのパネルとコピー操作は不要なためHTML/表示用JSを削除。LIFF認証、IDトークンを使ったWorker認証、起動時の待機、エラー処理、対戦表取得は維持。内部の起動時間計測ラッパーとServer-Timing値の受信は今後の検証用に保持するが画面には表示しない。
- 資産キャッシュは match.js?v=1660 に更新。

## 全画面のボタン・入力と閉じる
- 運用管理/試合/閲覧/ゲストに共通の stage-ui.css?v=1660 でボタン、テキストボックス、プルダウンの上下paddingをさらに圧縮。タップ可能な主要操作は高さ44px以上、入力は高さ44px以上を維持。LINE認証・disabled/色分け・排他処理は一切変更しない。
- 集金ホームの「立替精算」「運用管理」及び運用管理メニューの全ボタンは、既存の非青色メニューボタンと同じ薄灰色/枠線の btn-outline に統一。保存/確定/削除/承認などの業務操作色は引き続き区別する。
- 狭い画面で、管理用ダイアログのタイトルと「✕閉じる」を同じ行へ配置。空間が足りない場合は追加・更新などの補助ボタンを次の行へ移す。元のボタンID・イベントハンドラは使い続け、確認/編集ポップアップには新しい閉じるボタンを追加しない。収支表の見出し/追加/閉じる同じ行は維持。

## 参加者一覧
- メンバー・ビジター両方のカードからLINE IDを削除。メールアドレスは復活させない。常に「登録日」「更新日」、任意で「備考」を表示。会員の利用申請日は参加連絡の登録日ではないため、別表示の「利用登録日」も非表示。
- メンバーの登録日：操作履歴の初回出欠連絡（attendance.submit）。更新日：出欠再連絡の最終日時と完了済み参加者編集アーカイブの日時のうち最新の日付。
- ビジターの登録日：承認日時。更新日：完了済み参加者編集アーカイブの日付。出欠・参加者の変更履歴がない場合は「未記録」、登録と最新報告が同一なら「未更新」。日付の推測・旧行書き換えはしない。
- APIのLINE本人IDは認証との整合性のため内部保持。**画面だけから削除**。新しいタイムスタンプは既存「参加者操作アーカイブ」を読み取るだけでシート変更なし。

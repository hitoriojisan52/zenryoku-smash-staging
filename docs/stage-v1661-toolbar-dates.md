# v0.16.61 — 月・日程・参加者・ビジターの操作行整理、年月日時刻表示、最小上下余白

更新日: 2026/11/19。ユーザー明示要望。v0.16.60の権限・会計・参加者修正・日付管理を維持したUI変更。

## 画面ごとの変更

- 全体収支管理表：「対象月／前月／翌月／＋」を同じ一行。新規追加は表示「＋」のみ、aria-label「収支を追加」。同じ newLedgerRow ボタンとイベントを使う。タイトル行は閉じるのみ。
- 練習日程マスタ：「＋ 日程追加」「🔄 更新」を見出しの直下、一覧の上に一行で配置。元のscheduleAdd、scheduleReloadを再利用。
- 参加者一覧：プルダウンの右に「🔄 更新」を一行で配置。選択肢は「2026/11/28(土) 09:00～13:00 曽谷公民館」の日付・曜日・時刻・場所順。
- ビジター登録/管理：いずれもプルダウン右隣に「🔄 更新」を一行で配置。日程の完全表示と「すべての日程」、削除済み開催日の申請履歴を維持。新規申請折りたたみの先頭＋を削除し上下中央揃え。
- メンバー権限管理：「登録申請」と「🔄 更新」を同じ行に配置。既存の承認・権限変更・ロックの仕様維持。
- 対戦表：コート設定、参加者・固定ペア設定の折りたたみ見出しを上下中央揃え。開閉・操作は元のまま。
- その他：全画面の更新ボタンに🔄、ボタン・テキストボックス・プルダウンの上下paddingを0px。左右余白は原則維持し、主要ボタンと入力の44pxタップ/入力高は維持。

## 既存データと処理の保護

- 共通 date-format.js の SMDate.practiceLabel で時刻9:00は09:00として表示。内部の開催日値やpracticeIdを変更しない。
- dialog-close.jsはタイトル行に閉じるのみ移動する。追加・更新の実ボタンノードは日付/セクション行に置いたままで、元のイベントとariaを維持する。
- 収支確定順序・残高・集金・出欠/ビジター承認・参加者一覧ソート・試合の権限、GAS/Worker業務処理、Google Sheetsの値は変更しない。
- 対戦表遷移時「全力スマッシュ 検証対戦表操作へ移動しました。」の文言は検証用リポジトリのライブ画面・GAS・Workerに存在しない。LINE側のLIFF表示名等が生成している可能性があり、GitHubコードから該当メッセージを偽装して置き換えない。希望文言は「全力☆スマッシュ 対戦表へ移動しました。」。LINE Developersの検証用LIFF設定側で原文の確認が必要。本番側は触らない。

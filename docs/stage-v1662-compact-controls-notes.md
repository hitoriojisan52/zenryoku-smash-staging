# v0.16.62 — 現行アプリに近い操作高さと備考の表示差分

更新日: 2026/11/19。ユーザー添付スクリーンショットの左側（現行アプリ）を目標とし、右側（検証UI）の入力欄・ボタンが過大な問題を改修する。

## 要求・適用範囲

- **ボタン、テキストボックス、プルダウンの操作領域の高さも切り詰める**。従来は上下のpaddingだけ0にしても、共通CSSのmin-height:44px指定が効いていた。今回は新たな後置ルールでボタン/単一行入力/選択欄を原則**38px**にする。現行アプリとの一致を目指すが、端末/OS標準UIにより見た目の数px差があり得るため、実機で受入する。
- 「当日補正」「当日支出」の金額入力、領収書ボタン、収支確定ボタン、ダイアログ閉じる、日程プルダウン、集金管理メニュー、対戦表ボタン等に共通適用。現金確認の金種増減ボタンは明示的なheight:44pxを38pxへ。月選択/＋も38pxにし、v1661の一行配置を維持。
- 左右padding、幅、box-sizingや文字のサイズを新たに変更しない。金額欄の横幅も維持。checkbox/radioの表示寸法とARIA、フォーカス、色、disabled、保存処理、ロック、スクロール仕様は変更なし。
- 折りたたみ見出し（ビジター新規申請・コート設定・参加者固定ペア）のタップ高さ44pxは、開閉操作の誤タップを防ぐため維持。
- **集金管理ホーム**の参加者一覧に表示する備考だけを赤色（#c62828）、太字に変更。専用class「participant-memo」を実データの備考がある時だけ付与し、参加者名や集金額、管理画面の備考に赤色を波及させない。
- **運用管理 → 参加者一覧画面**では備考行を「📝 申請時の説明」のように表示し、「備考:」を削除する。入力された備考自体は無変更。ビジター登録/承認カードは今回の対象外。

## 保護・試験

- 修正ファイルは共通CSS/画面のCSSキャッシュ更新、renderHomeのmemo classとrenderParticipantManager_のmemo文言、回帰テスト、ドキュメントのみ。GAS、Worker、Google Sheets/会計・集金・退会・権限・試合のデータやAPIは変更しない。
- tests/check-stage-compact-controls-v1662.cjs はCSS末尾の38px!重要度・対象・横幅保護、備考赤字のスコープ、LINE ID無しの参加者カード、4画面キャッシュバスターを検証する。
- 既存の実 renderHome() 試験で実際の備考DOMにmeta participant-memoが付くこと、参加者一覧の既存DOM試験で「📝」のみの備考を確認する。
- 金額入力が意図せず変化しないこと、集金一覧だけスクロールすること、確定不可や未確定/確認順序などの回帰は従来のCIを維持する。本番は承認制で未変更。

## 実機での次の確認

1. 集金ホームの当日補正と当日支出の入力欄、領収書、収支を確定が現行アプリ（添付画像左側）に近い高さになったか。残金や集金額の表示は以前どおりか。
2. 日付プルダウン、参加者管理の修正/削除、メンバー権限、ビジター、対戦表/試合操作のボタンが過度に小さくなく、押し間違いが起きないか。
3. 集金ホームの備考のみ赤字で、他の情報の色は不変か。
4. 運用管理→参加者一覧で備考が「📝 コメント」のように表示され、「備考:」が出ないか。
5. 今回のUI改修は閲覧だけでほぼ確認でき、金銭保存操作は不要。LINE実機の受入をもって完了とする。

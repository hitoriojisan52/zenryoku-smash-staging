# v0.16.63 — 集金ホームの実高さ・残金欄・備考とビジター/会員表示の修正

2026/11/19 ユーザーが現行アプリ（左）と検証画面（右）を並べたスクリーンショットを再提示。前版v1662では「ほとんど変わっていない」と実機報告。

## 高さが縮まらなかった具体的な原因

1. v1661は上下paddingのみ0pxにしたが、共通CSSに button/input/select の **min-height:44px** が残っていた。
2. v1662で部分的に38pxへ縮めたが、**その38pxを !important の新しい下限・高さとして固定**した。そのため見た目の縮小は44→38pxの約6px分にとどまった。
3. スプレッドシートではなくUIの従来 `style.css` が集金額欄 `.income-block` を **flex-direction:column** に指定。右の画面では「当日補正(+0円)」が別行になり、残金欄全体が高くなっていた。さらに `.home-footer-action strong` が16px、金額欄の親にも縦paddingがあり、部品の38px下限だけを下げてもフッターが長いままだった。

## 実際の修正

- 全画面ボタンの **最小高さ30px**、単一行input/selectの **CSS内容高さ28px（枠線込み約30px）** に指定。v1662の38pxより**後ろ**に置く !important ルールで確実に優先。閉じる、月切替、現金確認の増減ボタンなどID/詳細セレクタも上書きする。ボタンが2行に折り返す場合は高さが自然増加し、文字を切り落とさない。
- 集金ホームの「当日補正」「当日支出」の親ボックスは縦padding2pxへ、残金欄も縦padding3pxへ。集金額・当日補正は可能な幅で**一行に並べる**（狭い画面では折り返し許容）。数値・収支計算・会計処理・変更履歴は不変。残金の文字サイズは基の14pxへ近づける。
- 「全力☆スマッシュ 運用管理」の見出しを17px→15px、幅620px以下は14pxへ少し縮小する。メニューやタイトル文言は維持。
- **集金ホームだけ**備考は赤字**通常ウェイト**。太字という誤った前版指定を打ち消す `font-weight:400!important` を後置。参加者一覧や他の文字色には影響させない。
- ビジター申請画面タイトルを「👤 ビジター申請」に修正。ビジター登録/管理両一覧から「カナ：」行・備考の「備考:」接頭語を削除。申請日時→「📅 申請日」、ビジター管理の申請者→「👤 申請者」。カナ自体は登録/編集データとして維持する。
- 現金確認の「枚数をリセット」は青色に変更。リセット**確認ダイアログの実行ボタン**は破壊操作の注意喚起のため赤色のまま。現金データとリセット時の確認は不変。
- ビジター管理一覧上部の冗長な説明文「申請内容を確認し、承認または却下を選択してください。却下後の再承認はできません。」を削除。承認/却下の戻せないルールは変更なし。
- メンバー権限管理では「🔤 氏名カナ」「🆔 LINE ID」を表示、「📅 利用登録日」→「📅 登録日」に変更。本人IDや日時の保存値は維持。

## 計測・回帰・受入

- GitHub自動テスト `tests/check-stage-visual-delta-v1663.cjs` により、44px→38px止まりの旧指定を**後置30pxが上書きしている**こと、外側の親ボックスと集金額の追加1行も解消していること、左右幅を変更していないことを静的に固定。
- 旧の訪問者実DOM回帰 `tests/check-stage-visitor-ui-v1641.cjs` は申請日・カナ非表示・申請者絵文字・備考接頭語削除を検証。
- 既存の集金/残高/収支確定順序・ビジター申請と不可逆の却下・メンバー権限・LIFF・対戦表・退会は全て保護。
- この変更では **GAS/Worker・検証用Sheetsのデータ・本番のいずれも変更しない**。実機での大きさはブラウザのOS拡大率に依存し得るため、検証用LIFFを閉じて再起動し、新しいstage-ui.css?v=1663を確実に読み込んで確認する。
- ユーザーへは「当日補正」「当日支出」欄・残金欄の高さ、ホームの赤字（太字でない）備考、各ビジター/会員管理の表記、現金確認のリセット色を実機で確認いただく。保存操作は不要。

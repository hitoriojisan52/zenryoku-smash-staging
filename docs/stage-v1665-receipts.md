# v0.16.65 — 領収書・精算日曜日・削除済み練習日再登録

## ユーザー要望・設計
- 立替精算（ホームからの追加）と全体収支管理表の「収支を追加・修正」で、精算日の日付入力に選択曜日を補足表示。元のYYYY-MM-DD保存値は変更しない。
- 練習日（削除行を再登録）は、**実際に ledger.change/delete が成功した操作履歴**があり、現在収支行が存在しないものだけ選択可能。未公開/未生成/未来日の練習を「削除行」と誤認しない。UIに加えGAS側でも同じ条件を再検証する。
- 集金ホームの「🧾 領収書登録」は開催日（P-行）に添付。ホームに「📄 表示」を設ける。
- 立替精算画面及び全体収支管理表の精算登録/修正で添付可能。保存済みの収支行（R-行）に、その行のversionを確認してファイルを後から紐付ける。
- 全体収支管理表に既存領収書の確認リンクを設ける。**確定後の編集/削除ボタン条件や当番担当と管理者の1ボタン仕様は変更しない**。
- 現状は1収支行につき領収書1ファイル。上書きした旧ファイルは非公開保存先に残し、誤削除を防止。多枚数添付や削除は将来の別要件。
- 1ファイル1.5MB、PDF・JPEG・PNG・WebPのみ。クライアント/Worker/GASで形式とサイズを重ねて検証し、GASでは先頭バイト（マジックナンバー）も検証する。

## セキュリティ・保存
- LINEのIDトークンをCloudflare Workerで検証し、GASでLINE会員かつ当番担当以上の権限を検証。ゲスト・未登録LINE・一般メンバーは拒否。
- 専用POST `/api/receipt/upload` の入力制限は2.2MB（base64を含むため）。他のAPIは32KBを維持。GET `/api/receipt/get` も認証必須で、ファイル本体をJSON base64で返却、ブラウザのBlobとしてローカル保存する。
- GASは厳密な収支行ID、未確定、バージョン一致、操作ID重複排除、ScriptLockの元で保存。**領収書保存で残高・収入・支出を変更しない**。
- 保存先はGoogle Driveの専用**非公開**フォルダ。検証スプレッドシートID `1XcsXwrPdRfDSPs8ibD7bfOGBM7zMxeSINFc9YlFBwac` と一致するときだけフォルダを初回作成し、GASの Script Properties `RECEIPT_FOLDER_ID` に記録する。本番のシートIDでは領収書書込みを拒否する。公開Drive URLや権限共有は一切発行しない。
- DriveApp権限がGAS側でまだ承認されていなければアップロードはSETUPエラー。**GAS実行アカウントによるDriveアクセス権の初回承認が必要な場合がある**。GitHub Actions/Claspのコード更新だけでGoogle OAuthを代行できないため、検証実機受入前に権限とフォルダが作成されるか確認が必要。
- 精算フォームでは先に収支行を作成/変更し、その後に領収書を添付。**添付に失敗しても収支行は登録済み**であり、ユーザーに明示して収支表から同じ行への再添付を案内する（元の精算を二重登録しない）。
- 上書き・バージョン競合は既存行の optimistic concurrency 機構に従う。確定済み収支行に添付は不可、閲覧は可能。

# v0.16.67 — 精算日の曜日の欄内表示・iPhone領収書写真対応

更新日：2026/11/19。根拠：ユーザーの立替精算実機スクリーンショットと、曜日の入力欄内表示・JPG/iPhoneカメラ画像対応の指示。

## 変更内容と旧業務仕様

- 精算日：立替精算/全体収支管理表の収支追加修正の2か所で、ネイティブ日付入力を内包する欄内右側に曜日を重ねる（例：2026/11/19　（木））。日付入力自体はtype=dateで保存値YYYY-MM-DD、カレンダー選択・必須検証を保持。ヒントはpointer-events:noneでクリックを遮らない。
- JPG/JPEG：従来からGAS/Workerがimage/jpegを受理していた。1.5MB以下は無変換で保存（拡張子またはMIMEが曖昧な場合は整合）。PDF/PNG/WebPの既存対応も維持。
- iPhone HEIC/HEIF：写真選択時にSafari/WKWebViewがHEICをデコードできる場合、ブラウザ内でJPEGへ変換。Safariから既にJPEGで返った画像は通常無変換。外部画像変換サービスには送らない。WebKit非対応時は理由を明示して拒否。
- 大きい写真：画像の元ファイルは最大25MBまで受け付け、段階的に長辺と品質を調整してJPEG1.5MB以下へ変換する。写真元データはユーザー端末で保持。PDFの1.5MB上限は変更しない。小さいJPEG/PNG/WebPは品質・ファイル名を維持。
- 立替精算のPOSTより前に画像変換を完了するため、端末がデコードできない場合は未登録の会計行を作らない。会計保存後の添付だけ失敗した場合はv0.16.66の永続的な警告と同一行への再添付を維持。
- Cloudflare Worker/GASのサイズ1.5MB、マジックバイト、LINE本人認証、当番担当権限、操作ID、ScriptLock、版数排他、全体収支の確定順序/残高計算は一切変更しない。

## 注意事項・影響

- HEIC→JPEG/大きな画像の圧縮は画像の再符号化を伴う。元のiPhone写真は変更しないが、Drive上の領収書は変換後JPEG。小さな文字の判読性はLINE実機での受入項目。
- カメラ/写真/ファイル/PDF選択の選択肢を維持するためHTMLのcapture属性は付けない。
- Safari/WebKit 17+のHEICデコードに依存するため、端末・iOS・LINE WebViewの組合せでHEIC変換ができない場合がある。JPEGで再選択するよう案内する。これを一律のHEIC保存対応とは扱わない。
- 新テスト tests/check-stage-iphone-receipt-weekday-v1667.cjs で両画面の欄内曜日・JPG無変換・HEIC→JPEG・JPEG縮小・PDF制約・変換失敗・収支行保存前処理を保護する。既存全会計/権限/集金/試合/退会も回帰。
- LINE実機のiPhone写真/カメラ選択、Driveアップロード/閲覧、文字の判読性は未受入。自動テスト合格やGitHub反映と混同しない。
- 本番環境は明示承認まで変更しない。検証用Sheets/Driveに保存されている既存収支・領収書の自動書換え/削除もしない。

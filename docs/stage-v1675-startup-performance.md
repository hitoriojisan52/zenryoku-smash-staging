# v0.16.75 — 集金管理画面の起動不能・全体性能の一次改善

2026-11-20 検証環境のみ。本番未変更。ユーザーは『読み込みが長く、集金管理画面が開かなくなった。全体的な性能を今一度見直したい』と報告。

## ソース上で確認された問題と対処

| 部位 | 改修前の動作／問題 | 検証版での改善と安全境界 |
| --- | --- | --- |
| 初期日付 | `live.js.reload` が `/api/overview` をpracticeId未指定で呼び、GASは一番最後の日程を既定選択。UIが本日以降の直近日程へ選び直すと**2回目**の `/api/overview` を送信。各回はLINEトークン検証、GAS、Sheet取得等を伴う | UIは `selectEligible:true` を付ける。認証・ScriptLockのある既存 `/api/overview` が**初回から**本日以降の直近日（確定済み当日も閲覧可）を選択。既存のpracticeId指定・過去未確定の手動選択も維持。以前のGASがflagを無視する場合のUI側フォールバックは保持 |
| GASの日程読込 | 一回のoverview内で `practices_`→`practice_`→`collectionState_`二回分の `practices_` が重複読込 | 同じrequest内で `practices_` の結果を `overview_`、`collectionState_`、`ensureCollectionLedger_`、既存自動収支生成時 `practiceIncome_` で再利用。その他のGAS操作の呼出しは従来の都度参照を維持。メンバー権限のキャッシュは追加しない |
| 停止時のスピナー | LIFF SDK初期化やWorker/GAS読込が返らない場合に無期限の全画面ロックが続く | LIFF初期化は20秒、通常の読込API (`session`,`overview`,`participant/list`,`visitor/practices`,`visitor/mine`) は25秒で中止し、**共通エラーダイアログ**で再度開く/手動更新を案内。Google/LINE応答を無期限待ちしない。権限やIDトークンのデータは露出しない |
| 書き込みの結果不明 | 通信を途中で切るとGASが書込済みでも応答が届かず、二重操作や残高不整合の危険 | payment/ledger/receipt/attendance等の書き込みにタイムアウトや自動再送は追加しない。`overview`はlazyな確定前P行生成のみ可能な既存の固定ID/Lock/audit経路を維持 |
| 自動更新と別画面操作 | ホームの8秒自動更新は当番メニュー・収支管理・参加者管理のモーダルが開いていても走り、LINE認証/Worker/GASを繰り返し呼びロック競合要因になりうる | **管理ダイアログ表示中はホーム自動更新を一時停止**。ホームに戻れば従来の8秒ごとの自動更新を再開。自動更新は全画面ブロックしないという確定UI仕様を維持 |
| 診断 | 従来は集金保存の `perf=1` だけに詳しいタイミングがあった | `?perf=1` で起動時のLINE初期化/会員確認/集金読込/合計を**秒単位でトースト**表示。実アカウントIDや秘密値を測定/記録しない。通常画面の表示は変更しない |

## 影響と先行仕様

- 旧v15の収支残高計算、過去日・同日順序の確定/解除、集金チェック冪等・排他・版番号、管理者/当番の都度権限チェック、参加者データとリッチメニューの仕様を変更しない。
- 未確定・確定解除した練習日は全日付表示、確定済み当日は閲覧可能、確定済み過去日/未来日は除外、起動初期値は本日以降の直近。日付プルダウンのv1674仕様をそのまま維持する。
- 新GAS `selectEligible` は任意パラメータ（互換性保護）。選択日が有効な場合は維持、確定済み過去日等の場合は直近に移動、直近がない場合は練習日未選択として従来のロックを維持する。
- 自動更新停止中にも管理機能の保存後の明示更新は従来どおり動作。通信停止時もアプリ内で操作成功を推測しない。

## 自動回帰テストと実機受入

- `tests/check-stage-startup-performance-v1675.cjs`でGASの実 `overview_` をモックSheetsで実行し、1回読込の選択、同日確定表示、過去の確定除外/未確定選択、候補ゼロ、レガシー互換、重複シート読込解消、LINE側 `reload()` の初期API呼数、時間切れエラー、会計writeがタイムアウトされないこと、8秒自動更新のモーダル一時停止を確認。
- UI/GAS/仕様CI、旧会計順序、退会・ビジター・LINE本人出欠認証の擬似テスト成功を別途確認。Pages、GAS既存デプロイ、Cloudflare Workers Builds、公開WorkerとLIFFの配信状態も独立確認する。
- **まだ解明されていない点**：利用者の実機の起動が止まった正確な工程、LINE/Googleの実応答時間。静的コードの2回読込が原因候補だが、今回の『開かなくなった』直接原因と断定しない。`?perf=1` で実機起動時間を確認するまで『高速化実測済み』と表現しない。
- LINE参加連絡の実機E2Eは未完了のまま。このホーム起動問題の復旧と安全性を先に確認し、その後に本人出欠送信/修正・権限別受入へ復帰する。

# v0.16.19 既存運用管理への段階統合（試験用）

- 既存ステージングの `live.html` に新しい管理画面を **?accessUi=v2 でだけ** 表示する
- パラメータがない通常の `live.html` は従来の `live-access.js` がそのまま動作する
- 新しい `live-access-v2.js` は、既存の管理者認証 `/api/session` と `/api/member/manage/list` を再利用
- 登録の承認/却下 `/api/member/manage/decide`、役割変更 `/api/member/manage/role` だけ許可。書き込み後に一覧で検証
- 初回・手動更新・保存中は全画面ロック。自動更新（運用管理のホーム）はロックしない
- 確認/エラーは専用ダイアログ。操作成功時は通知。通信断・競合時の更新を自動再送しない
- キャンセル後の役割プルダウンは未保存の選択値を保持。「更新」でサーバー値へ戻る
- 自分自身の権限は画面から変更不可（最終判断はGAS）
- 退会履歴は **APIが withdrawn 配列を返すときだけ** 「退会履歴を見る」を表示。配列のない旧Workerでは隠し、未対応を空履歴と誤認させない
- **退会操作・退会APIは未接続**。検証用固定 memberId や専用 Worker を使わない
- 本番のLINEリッチメニュー・本番GAS/Worker・既存の対戦表/集金ロジックは変更しない
- 一般メンバーと当番担当に管理メニューを表示しない。サーバー側権限判定は既存のまま

- LINE公式ドキュメントによると、LIFF URLに追加したクエリは初期化完了まで `liff.state` に格納される場合がある
- そのため画面選択用 `access-v2-mode.js` は直指定の `accessUi=v2` と `liff.state` 内の同じキーを確認する
- `liff.state` やURLの書換えは行わない。実際のLINE認証・API通信は従来通り `live.js` が初期化後に行う
- リンク: `https://liff.line.me/2012602642-XBSkXduO?accessUi=v2`
- 旧画面を開くには、パラメータなしの同LIFF URLを使う

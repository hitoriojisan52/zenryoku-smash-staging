# v0.16.93 — 共通UI：システムメッセージの表示領域・優先順位

確認日：2026/11/21。対象：全力☆スマッシュ検証用アプリ／運用管理・利用申請・試合・閲覧画面。従来の色の意味（v0.16.80～87）を踏襲し、画面上の位置の統一を明文化。

## 確定ルール

1. **同一画面で赤・黄・青・緑のシステムメッセージは必ず同じ上部領域**（画面タイトル、開催日の選択または概要情報の直下／入力・一覧・フッターの前）に表示する。ホームは `#stageHomeMessageRegion`、対戦表・閲覧ページは `.stage-message-region`。各管理ダイアログの状態表示も見出しの直下とする。複数メッセージがあればその領域内で縦に並べ、下部へ別の色付き通知を増やさない。
2. **色と意味**：青＝実際に処理／読取中のみ（CSSスピナーを使用）、緑＝操作正常完了、黄＝注意・制約・入力未充足、赤＝エラー。処理中ではない案内・件数ゼロ・説明文は中立の灰色とする。上記色を件名や装飾として使わない。内容のないステータスはCSSで非表示。
3. **例外の明確化**：当日補正／当日支出の保存状態は画面全体の色付き**システムメッセージ枠ではなく、対応する数値欄の左にある小さなフィールド内状態**。入力欄の直左に「保存中…」の青いスピナー／保存成功の緑チェック／入力警告／結果不明を表示する。数値と状態を同じ `.stage-money-save-pair` 内に置き、携帯の折返しでも分断しない。各画面の確認・エラーポップアップ、操作完了トースト（暗いオーバーレイ）、中立説明文は色付きシステム通知枠の配置制約とは別に維持する。ポップアップがある場合は同じ画面のインライン赤メッセージも上部領域に出す。
4. **財務保護**：警告位置や表示色は、GAS確定順序・残高・権限・ロック・操作ID・現金/集金編集の活性条件に一切作用しない。収支確定が実際に成立したかはGAS/Sheet上の状態で判定する。UIの見た目だけで確定済みと推測しない。

## 違反箇所の点検と今回の修正

| 対象 | 以前の位置・意味 | 修正 |
|---|---|---|
| ホーム「先行する未確定の収支」 | 「残金／確定」ボタンよりも下に黄枠 | 上部の共通メッセージ領域へ移動（集金制約の黄・通信エラーの赤と同じ場所） |
| 当日補正・当日支出の保存状態 | 金額入力の**下段**の独立行 | 各金額入力の**左隣**へ。状態・金額の不可分ペア化。狭い端末では領収書ボタンを折返してもペアを保持 |
| ホーム読込失敗 | 参加者カード一覧内に赤枠を作成 | 一覧を空にし、上部の既存赤枠 `stageInlineError` に表示。手動「更新」は継続可能、金銭操作は非活性 |
| ビジター申請・本人出欠・参加者一覧・利用者情報編集 | フォーム/日付選択の**後**に黄枠がある箇所 | 各画面・ダイアログの見出し直下または操作部前へ移動 |
| 管理者権限切換・管理者利用者一覧 | 通常の読取完了状態が青のinfoとなる箇所 | 読み込み中の青と、読取後の中立・注意・エラーを切り分ける。検証用の静的案内も中立/黄色の適切な意味を保持 |
| メンバー退会検証専用の説明／照合結果 | 管理者一覧の下方、任意の検証用サブセクション内に青枠 | 管理者画面の上部共通領域に移動。検証サブセクションが非表示ならその通知も非表示 |
| 対戦表作成・参加者用対戦表閲覧・ゲストQR閲覧 | エラーが開催日プルダウンや対戦表ヘッダーの**下** | ページヘッダー直後、共通上部エリアに移動。操作認可や試合進行は不変更 |
| 管理ダイアログの動的エラー | タイトル直下に新しい箱を作成する経路 | `.stage-message-region` がある画面はそこへ追加し、画面内に色付き通知を分散させない |

この監査は今回のGitHubソースに含まれる共通UIメッセージを対象とする。**中立の補助説明、フォーム別バリデーションテキスト、GAS実行結果をその場で示す非色付きステータス、操作完了トースト、確認/エラーダイアログは別の文脈のため一律に上部へ移動しない**。一部の動的状態の機種別レイアウトはユーザー実機受入が必要。

## 11/21の収支行と確定ボタンに関する訂正

ユーザーから「確定ボタンが確定解除ボタンにならない件は勘違いなのでご放念」と明示あり。**この件のボタン仕様・確定処理・APIは改修しない。** 前時点でSheetを読み取り照合したところ、11/19の立替/その他の収支は確定済、11/21の練習行はその照合時点では未確定だった。以降のユーザー操作を勝手に取り消したり推測して確定扱いしない。旧アプリの確定順序（最後の確定済み行のみ解除可能）を維持。
